## 🔍 关键技术点

### 1. 条件编译策略
```cpp
#ifndef NO_SDL
    // 桌面平台代码
#else
    // iOS 平台代码（如果需要）
#endif
```

### 2. 跨平台延迟实现
- **SDL 平台**: `SDL_Delay(ms)` - 轻量级，适合游戏和多媒体
- **标准 C++**: `std::this_thread::sleep_for()` - 跨平台标准库

### 3. 音频架构差异
- **桌面**: SDL Audio → audio_callback → 解码队列
- **iOS**: AudioQueue → fillAudioBuffer → 解码队列
