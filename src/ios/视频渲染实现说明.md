# iOS 视频渲染实现说明

## 实现概述

通过 C 桥接层实现了完整的 iOS 视频渲染功能，包括：
- ✅ 视频帧数据获取
- ✅ YUV 到 CVPixelBuffer 转换
- ✅ AVSampleBufferDisplayLayer 硬件加速渲染
- ✅ 音视频同步
- ✅ 倍速播放支持

## 核心文件

### 1. C 桥接层

**`include/player_core_c_bridge.h`**
```c
// 视频帧数据结构（C 兼容）
typedef struct {
    void* y_data;
    void* u_data;
    void* v_data;
    int y_linesize;
    int u_linesize;
    int v_linesize;
    int width;
    int height;
    double pts;
} VideoFrameDataC;

// 获取视频帧（不消费）
int player_core_get_video_frame(PlayerCoreHandle* handle, VideoFrameDataC* frame_data);

// 消费视频帧（渲染完成后调用）
void player_core_consume_video_frame(PlayerCoreHandle* handle);
```

**`src/core/player_core_c_bridge.cpp`**
- 从 C++ `FrameQueue` 获取视频帧
- 将 `AVFrame` 数据转换为 C 结构体
- 提供帧消费接口（队列推进）

### 2. iOS 渲染层

**`src/ios/PlayerCore_iOS.mm`**

#### 主要方法

##### `renderVideoFrame`
- 60 FPS 定时调用（通过 `CADisplayLink`）
- 获取视频帧数据
- 音视频同步检查
- 丢帧或显示决策

```objc
- (void)renderVideoFrame {
    VideoFrameDataC frame_data;
    if (player_core_get_video_frame(_wrapper->handle(), &frame_data) != 0) {
        return;  // 没有可用帧
    }
    
    // 音视频同步
    double delay = frame_data.pts - masterClock;
    if (delay <= -threshold) {
        // 视频落后，丢帧
        player_core_consume_video_frame(_wrapper->handle());
    } else if (delay <= threshold) {
        // 显示帧
        [self displayVideoFrameData:&frame_data];
        player_core_consume_video_frame(_wrapper->handle());
    }
}
```

##### `displayVideoFrameData`
- 创建 `CVPixelBuffer`
- 创建 `CMSampleBuffer`
- 提交到 `AVSampleBufferDisplayLayer`

##### `createPixelBufferFromFrameData`
- YUV420P 转 NV12 格式
- 硬件加速支持
- 平面数据复制和交织

```objc
// Y 平面直接复制
memcpy(yPlane + i * yStride, ySrc + i * frameData->y_linesize, frameData->width);

// UV 平面交织
uvPlane[i * uvStride + j * 2] = uSrc[...];      // U
uvPlane[i * uvStride + j * 2 + 1] = vSrc[...];  // V
```

## 关键技术点

### 1. 音视频同步

使用**音频主时钟**同步策略：
```objc
double masterClock = player_core_get_position(_wrapper->handle());
double delay = currentPTS - masterClock;
double threshold = 0.04 / playbackRate;  // 动态阈值
```

- 视频落后超过阈值 → 丢帧
- 视频在阈值内 → 显示
- 视频领先 → 等待下一帧

### 2. 像素格式转换

**FFmpeg YUV420P → iOS NV12**

| 格式 | 平面数 | 描述 |
|------|--------|------|
| YUV420P | 3 | Y、U、V 分离 |
| NV12 | 2 | Y 单独，UV 交织 |

iOS 硬件加速器更适合 NV12 格式。

### 3. 帧生命周期

```
FFmpeg 解码
    ↓
存入 FrameQueue
    ↓
C 桥接层 peek（不消费）
    ↓
iOS 层复制数据到 CVPixelBuffer
    ↓
显示完成后调用 consume（推进队列）
    ↓
FrameQueue 释放 AVFrame
```

### 4. 倍速播放支持

同步阈值根据播放速率动态调整：
```objc
double threshold = 0.04 / playbackRate;
// 1.0x: 40ms
// 1.5x: 26.7ms
// 2.0x: 20ms
```

## 性能优化

### 1. 硬件加速
- 使用 `kCVPixelFormatType_420YpCbCr8BiPlanarVideoRange` 格式
- 启用 `IOSurface` 属性，支持零拷贝

```objc
(NSString *)kCVPixelBufferIOSurfacePropertiesKey: @{}
```

### 2. 渲染频率
- `CADisplayLink` 自动适配屏幕刷新率
- 设置 `preferredFramesPerSecond = 60`

### 3. 内存管理
- 使用 `CVPixelBufferRef` 引用计数
- 及时释放 `CMSampleBufferRef` 和 `CMVideoFormatDescriptionRef`
