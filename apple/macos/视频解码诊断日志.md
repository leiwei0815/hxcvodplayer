# 视频无画面问题 - 诊断日志增强

## 问题现象

- ✅ 音频播放正常（有 "已解码 N 个音频帧" 日志）
- ❌ 视频无画面（**没有** "已解码 N 个视频帧" 日志）
- ✅ CVDisplayLink 已启动
- ✅ 视频解码器已恢复

## 问题分析

视频解码线程在运行，但没有成功解码任何视频帧。可能的原因：

1. **视频解码器一直处于暂停状态**
2. **decode_frame() 一直返回错误**
3. **视频包队列为空**
4. **视频流打开失败**

## 修复内容

### 增强视频线程日志

在 `src/core/hxc_player_core.cpp` 的 `video_thread()` 函数中添加了：

1. **暂停状态日志**
```cpp
while (video_decoder_ && video_decoder_->should_pause() && !abort_request_) {
    if (error_count == 0) {
        LOG_INFO("视频解码器暂停中，等待恢复...");
        error_count++;  // 只打印一次
    }
    PLAYER_DELAY(10);
}
```

2. **恢复状态日志**
```cpp
if (video_decoder_ && !video_decoder_->should_pause()) {
    if (error_count > 0) {
        LOG_INFO("视频解码器已恢复，开始解码...");
    }
    error_count = 0;
}
```

3. **详细的错误日志**
```cpp
if (ret < 0) {
    if (ret != AVERROR(EAGAIN)) {
        error_count++;
        if (error_count <= 3 || error_count % 100 == 0) {
            LOG_ERROR("视频解码错误: ", ret, " (错误次数: ", error_count, ")");
        }
    }
    PLAYER_DELAY(10);
    continue;
}
```

## 可能的原因和解决方案

### 原因 1: 视频流打开失败

**症状：** 没有看到视频相关的任何成功日志

**检查：** 查看打开文件时的日志
```
[INFO] 打开视频流...
[INFO] 创建视频解码器...
[INFO] 启动视频线程...
[INFO] 视频流打开成功, 分辨率: 1920x1080
```

如果这些日志不完整，说明视频流打开失败。

**解决：** 确保视频文件有视频轨道

### 原因 2: 视频包队列为空

**症状：** 视频解码器恢复，但一直没有帧输出，也没有错误

**原因：** 读取线程没有正确读取视频包

**解决：** 检查 `read_thread()` 是否正常运行

### 原因 3: 解码器初始化失败

**症状：** 大量解码错误

**原因：** 视频编解码器不支持或初始化失败

**解决：** 尝试使用标准 H.264 编码的 MP4 文件
