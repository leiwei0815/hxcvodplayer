# macOS 播放器修复说明

## 核心发现

**iOS 项目使用相同的 `hxc_player_core_c_bridge.cpp` 是正常的！**

因此，**不需要修改共享的核心代码**，只需修改 macOS 特定的实现。

## 修改文件

### 仅修改 2 个文件（macOS 特定）

1. ✅ `src/macos/HXCPlayerControl.mm`
2. ✅ `src/macos/HXCPlayerView.mm`

### 不需要修改

❌ `src/core/hxc_player_core_c_bridge.cpp` - **保持原样**

## 关键修复点

### 1. 视频渲染 - 添加 controlTimebase

```objective-c
// 在 HXCPlayerControl 的 init 方法中
CMTimebaseRef controlTimebase;
CMTimebaseCreateWithSourceClock(kCFAllocatorDefault, 
                               CMClockGetHostTimeClock(), 
                               &controlTimebase);
_videoLayer.controlTimebase = controlTimebase;
CFRelease(controlTimebase);

CMTimebaseSetTime(_videoLayer.controlTimebase, kCMTimeZero);
CMTimebaseSetRate(_videoLayer.controlTimebase, 1.0);
```

**为什么？** macOS 的 `AVSampleBufferDisplayLayer` 必须设置 timebase。

### 2. 音频质量 - 增大缓冲区

```objective-c
// 从 1024 增加到 4096 samples
UInt32 bufferSize = 4096 * channels * sizeof(SInt16);
```

**为什么？** 更大的缓冲区减少回调频率，音频更流畅。

### 3. 调试日志

添加了详细的初始化和运行日志，方便排查问题。
