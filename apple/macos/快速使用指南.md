# HXC Player - macOS 纯 Cocoa 版本快速使用指南

## 🚀 快速开始

### 1. 安装依赖
```bash
brew install ffmpeg sound-touch sdl2 cmake
```

### 2. 编译项目
```bash
cd /Users/debug/project/YXVodPlayer/src/macos
./build.sh
```

### 3. 运行应用
```bash
open build/bin/HXCPlayer-macOS.app
```

## 📖 使用说明

### 打开视频
1. 点击 **[打开]** 按钮
2. 选择本地视频文件（MP4, MKV, AVI, MOV, FLV, WMV）
3. 视频会自动开始播放

### 播放控制
- **播放/暂停**: 点击 **[播放]** 或 **[暂停]** 按钮
- **停止**: 点击 **[停止]** 按钮
- **进度条**: 拖动顶部滑块跳转到指定位置

### 音量调节
- 拖动 **[音量]** 滑块调节音量（0-100%）

### 速度调节
- 从 **[速度]** 下拉菜单选择：
  - 0.5x（慢速）
  - 0.75x
  - 1.0x（正常）
  - 1.25x
  - 1.5x
  - 2.0x（快速）

### 显示模式
- 点击 **[适应]** 或 **[填充]** 按钮切换视频显示模式
  - **适应**: 保持宽高比，可能有黑边
  - **填充**: 填充整个窗口，可能裁剪画面

## 🔧 开发说明

### 项目位置
```
/Users/debug/project/YXVodPlayer/src/macos/
```

### 主要文件
- `main.mm` - 应用入口
- `AppDelegate.mm` - 应用代理
- `PlayerViewController.mm` - 播放器视图控制器（UI 逻辑）
- `CMakeLists.txt` - 构建配置

## 💡 提示

1. **网络视频**: 修改 `PlayerViewController.mm` 中的 `openButtonClicked:` 方法，取消注释网络 URL
2. **自定义 UI**: 修改 `setupUI` 方法调整界面布局
3. **添加功能**: 参考 `HXCPlayerControl.h` 的 API 文档

## 📝 代码示例

### 播放指定 URL
```objective-c
[self openURL:@"https://example.com/video.mp4"];
```

### 修改默认音量
```objective-c
_player.volume = 0.5;  // 50% 音量
```

### 修改默认播放速度
```objective-c
_player.playbackRate = 1.5;  // 1.5倍速
```
